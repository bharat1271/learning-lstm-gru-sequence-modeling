# LSTM & GRU Sequence Modeling

This project was developed while learning sequence modeling using Recurrent Neural Network (RNN) variants in TensorFlow and Keras.

The objective of this project is to understand how Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU) architectures process sequential text data and generate predictions based on learned patterns.

---

## Project Overview

This repository contains multiple sequence modeling implementations built using different RNN architectures.

### Implemented Models

### 1. LSTM Model

Baseline Long Short-Term Memory model trained for sequence prediction.

Concepts Covered:

* LSTM Architecture
* Sequence Learning
* Hidden States
* Text Tokenization
* Sequential Prediction

---

### 2. LSTM with Early Stopping

Enhanced LSTM implementation using Early Stopping to reduce overfitting and improve training efficiency.

Concepts Covered:

* Validation Monitoring
* Overfitting Prevention
* Model Generalization
* Training Optimization

---

### 3. GRU Model

Gated Recurrent Unit implementation for sequence prediction.

Concepts Covered:

* GRU Architecture
* Gating Mechanisms
* Efficient Sequence Modeling
* Model Performance Comparison

## Streamlit Application

The application allows users to compare predictions generated by different sequence models.

### Available Tabs

#### LSTM

Predicts the next word using the baseline LSTM model.

#### LSTM + Early Stopping

Predicts the next word using the optimized LSTM model.

#### GRU

Predicts the next word using the GRU architecture.
